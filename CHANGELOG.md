# Changelog

All notable changes to this project are listed here.

## 0.1.0

First release.

- Record a lecture from a microphone or from one app's sound (Windows), or import audio and Zoom recordings.
- Transcription with speaker labels, on an NVIDIA GPU or the CPU.
- Summaries and concept search from a local model run by Ollama; exact phrase search across every lecture.
- Classes, units and exam preparation.
- Verified compact Opus copies, duplicate detection, class suggestions, moving lectures, and Recently deleted.
- Automatic per-computer settings, a `doctor` check, and hash-pinned installers for Windows 10/11 and Apple Silicon Macs.
- Local only: the app listens on `127.0.0.1`, requires a sign-in cookie, and makes no network calls at run time other than to Ollama on loopback.
